Google Sheets Setup

  1. Create a brand-new blank Google Sheet.
  2. Open Extensions → Apps Script, delete any existing code, paste the script below, and click Save.
  3. Click Deploy → New deployment, choose type Web app, set Execute as = Me and Who has access = Anyone, then click Deploy.
  4. Copy the Web App URL and paste it below. The sheet headers will be created automatically.
